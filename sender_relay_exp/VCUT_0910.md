## 배선 [코드읽기] — `memory/visual_cut.py` (opt-in, off=훅 0)
- `VLMAS_VCUT=zero|mask|identity`, `VLMAS_VCUT_STAGE=R|A|RA`, `VLMAS_VCUT_LOG=1`
  - `zero` (②): native α(V∪C 위 softmax) 그대로 두고 visual 항 r_V=Σ_{j∈V} α_j v_j W_O 만 0 (mass는 쓰고 내용은 안 읽음)
  - `mask` (①): visual 열을 softmax에서 제외(renormalize) = visual KV access 차단
  - `identity`: 컷 없이 재계산(배관 검증; native와 bf16 오차 내 동일해야 함)
- 적용 row: R = Reasoner latent step(step당 1 row, 전 step, 전 36층; `qwen3vl._visual_cut_ctx`로 두 latent 루프 모두 감쌈) / A = Answerer 프롬프트 프리필 **전 row**(causal mask 직접 계산) + 생성 토큰 전부 + VER score-only 채점 forward(margin이 같은 컷 아래서 계산되도록 `latent_qwen_engine`의 VER 호출도 감쌈)
- text/latent K/V 열은 건드리지 않음(제거·재계산 없음). Reasoner 프롬프트 텍스트 row의 visual 읽기는 R 컷에 포함되지 않음(텍스트 KV 보존 원칙) — 캐비앗.
- 사고 1건: `_visual_bind_step`의 `@contextlib.contextmanager`와 def 사이에 새 메서드를 삽입해 데코레이터가 잘못 붙음 → 스모크 4/4 rc=1 → 위치 수정 후 재가동.

## W_a 수축 체크 [CPU실측, safetensors에서 직접 재구성]
Qwen3-VL-4B-Thinking은 `lm_head` 없음(tied) → W_a=(EᵀE+1e-5 I)⁻¹EᵀE: ‖W_a−I‖_F/‖I‖_F = 2.2e-6, 특이값 0.99998~1.00002, 임의 방향 ρ=‖ΔW_a‖/‖Δ‖ = 0.9999996~1.0. → **ρ_t≡1, W_a가 visual-conditioned 성분을 압축할 수 없음. alignment 축 종결**(no-W_a ablation 불필요).
