# LaVIM Nav4

Source release for the Nav4 visual patch-navigation pipeline.

This repository contains the Nav4 implementation, supporting pipeline code, tests, and launch scripts. Generated run outputs, patch images, datasets, model weights, caches, and temporary artifacts are intentionally excluded.

## Main Nav4 module

`vision_text_mas/onepass_navigation_nav4.py`

## Run entry point

`sender_relay_exp/rtask_nav4_arm.sh`

See `requirements.txt` for Python dependencies.
